Himpunan Mahasiswa Informatika

HMIF adalah organisasi kemahasiswaan tingkat program studi di Fakultas Ilmu Komputer, Universitas Pancasila. Organisasi ini menjadi wadah pengembangan minat, bakat, dan keterampilan mahasiswa Informatika di bidang akademik maupun non-akademik.

Program Kerja

Beberapa program kerja unggulan yang rutin dijalankan setiap tahun:

  • Pelatihan pengembangan web dan aplikasi mobile
  • Seminar teknologi dan karier di bidang IT
  • Kompetisi coding tingkat mahasiswa
  • Bakti sosial dan pengabdian masyarakat berbasis teknologi

Alur Pendaftaran Anggota Baru

Calon anggota dapat mengikuti tahapan berikut untuk bergabung dengan HMIF:

  1. Mengisi formulir pendaftaran daring melalui tautan yang dibagikan panitia
  2. Mengunggah berkas persyaratan (KTM dan pas foto)
  3. Mengikuti sesi wawancara singkat dengan pengurus
  4. Mengikuti masa orientasi anggota baru
  5. Pengumuman resmi status keanggotaan

Info lebih lanjut mengenai jadwal pendaftaran dapat dilihat pada akun Instagram resmi HMIF atau langsung menghubungi kontak di bawah ini.
